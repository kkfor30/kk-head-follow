# 从主体素材到连续动作

## 三种任务范围

**新建首屏（默认）**：构图图只决定位置、姿势、镜头与光照。制作不含动态角色的背景、分别独立的透明角色及必要的阴影；用这些真实素材拼出目标首屏，再检查静态融合。后续视频沿用同一角色身份、构图坐标和接触点，整角色渲染。详见 [layered-scene.md](layered-scene.md)。不要先生产纯色角色 demo，再临时决定如何拼回完整旧照片。

**独立角色组件**：用户只需要头像、宠物组件或明确授权的动作实验时使用。准备真实透明源；视频服务需要色键背景时，由程序合成均匀绿/洋红副本，避开主体颜色。固定身体接触点与构图，给整个运动范围留边。完整主体一起取帧，避免额外的头颈拼接。它的成功只验证动作链路，不能写成复杂场景已经可用。

**固定场景局部替换**：用户要求保留现有照片、布局、身份时使用。除了连续动作，还需要移除旧头的 clean plate、逐帧 Alpha、颈部衔接与遮挡处理。先读 background-delivery.md。不能用邻居或复杂背景进入生成区后原样矩形贴回；生成输入的安全余量和网页最终绘制范围分别标定。独立角色成功不代表这条路线已经验证。

素材足够时不重新生图。需要制作参考时说明用途，保留身份、原有嘴部状态、表情和风格；不把案例里的闭嘴、微笑或宠物类型写成通用约束。

## 一次单主体小样

1. 先检查实际输入图与最终显示大小。首屏任务先完成分层静态合成；已有视频任务直接验证它与目标静态图的外观和坐标。新建方向环默认准备真实向上的接缝参考，同图作为首尾；中性状态单独处理。遵循 prompt-patterns.md，不能只把中性图片改名为 up。透明图片作为输入不意味着视频输出带 Alpha，须核查成片格式再去背景。
2. 先生成一个 5 秒/768p 小样，明确首尾约束、单一连续轨迹、眼神跟随与固定项。不预设八个定点停留，不把长时长当完整动作保证。
3. 先按 iteration-delivery.md 对原始视频分级，再决定完整图集、有限方向或仅合成播放；完整方向图集需要真实方向覆盖。先检查完整方向、眼神、首尾前后多帧趋势、身体稳定、画面裁断。母版动作失败时保存证据并修正上游；不能无限增加修复尝试。
4. 完整动作的采样密度不足时，比较原生与 2× 插帧；用实际显示大小决定是否值得采用。雪碧图仅打包，不会修复动作。不要机械凑某个总帧数。
5. 在已确定的目标首屏核验完整顺逆向循环及回正、身体接触点与遮挡，再扩展其他主体。纯色页只用作定位素材或抠像问题的辅助对照；不能代替真实背景验收。

## 连续视频插帧

```text
python scripts/densify_head_video.py --video source/master.mp4 --output build/dense-candidate --max-side 512
```

需要 OpenCV 和可调用的 FFmpeg/FFprobe；可用 --ffmpeg 和 --ffprobe 指定路径。只接受恒定帧率。工作分辨率可显式缩小，但不得低于目标显示所需清晰度；原视频保留不动。

工具保留每张工作尺寸的原生解码帧，使用 FFmpeg 运动补偿只补相邻时刻的半帧；N 张原生帧输出 2N−1 张，首尾不相连、不外推缺失动作。边界计算用复制上下文，复制帧不进入导出。lineage.json 记录每张原生/新增帧与父帧；candidate.mkv 使用 FFV1 保存像素，frames/ 是编译用 PNG。

review/ 中每行是“原生→新增→原生”，逐页检查眼睛、嘴、耳缘、毛发和遮挡。任何数据报告都不自动证明视觉通过。先在 RGB 色键母版上补帧，再处理透明边缘；插帧可能污染色键边界，需比较抠图结果。透明素材要使用预乘 Alpha 处理，不能把未定义的透明 RGB 直接拿去估计运动。

插帧之后重新标定或按 lineage 转换旧锚点（保留全片时原生帧 i 对应 2i）。编译 spec 的 sourceVideo 指向 candidate.mkv，frameLineage 指向 lineage.json，originalSource 指向原视频，三者均为项目相对路径。编译器核对哈希并标出 synthesized 与 nativeProvenance，核验器拒绝来源丢失或媒体变化。裁段、删帧和合成之后，索引不能继续套用旧值。

## 独立角色与现有运行时

现有清单可以将整只角色占用的场景区作为 crop，而非必须裁头。baseImage 是含角色的静态降级图，cleanPlate 是同尺寸的空场景；视频产物走 page/chroma-key。保留这两个不同角色的底图，避免先画静态角色再叠透明角色导致双轮廓。中性回正图应来自真实中性输入/视频帧；没有中性素材就明确以接缝姿态作为静态休息态，不能改标签宣称正视。

新流程的提示词和默认参数仍须实际样例验证。单个演示通过不是任意人物、宠物、背景的一次成功保证。
