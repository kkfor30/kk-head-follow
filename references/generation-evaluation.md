# 跨素材对照与证据边界

只在用户要求验证生成策略、或已有相应实验预算时执行新生成。修改 Skill、检查旧素材、单元测试不自动授权新增付费。现有失败素材可用于回归诊断，但不能证明新提示词的生成效果。

## 评估设计

选小规模但有差异的输入：写实与风格化人物、不同动物结构、正面与倾斜初姿态、配饰/遮挡、浅色与深色简单背景、纹理复杂背景、多角色邻近与前景遮挡。先用已有媒体验证合成和错误分流，再按预算验证新生成；不把所有组合机械跑一遍。保留一部分未用于调参的输入做复验。

按问题逐层对照：

1. 固定素材、模式和参数，比较提示词结构或扩写模式。
2. 固定主要描述，比较参考帧准备方式。
3. 对仍然漏动作的任务，比较首尾单片、动作参考、最少必要分段。
4. 有改善再扩展不同主体，最后用保留输入复验。

每次只改变主要研究变量；交付目的同时改多项可以，但结论只能是组合改善。固定 seed 便于记录，不保证服务可确定复现。不因一次偶然成功升级为通用默认，不用模型厂商宣传指标替代本任务数据。

## 每次试验最少记录

- caseId、主体类别、输入哈希、原始身份基准、spec、review、实际请求与服务返回扩写。
- 路线、模型/通道、时长、分辨率、seed、主要变化与保持项。
- 方向覆盖、头眼配合、身份、身体漂移、闭环、可用帧比例分别记 pass / fail / unknown，附源帧证据。
- 输入构图、母版动作、场景合成和真实交互分开评价；不同问题不能混成一个总分。
- 到获得可用候选所需的全部提交次数、请求总秒数、输入媒体、可获得的真实费用和处理时间；失败也计入分母。没有费用数据不推算确定金额。

观察指标按主体与目标定义，不能用同一个鼻尖位移阈值判断人、犬与卡通。瞳孔被遮挡则该项 unknown；像素差、光流、姿态检测只能辅助定位，不自动认证眼神与自然感。以最终显示尺寸核对可见缺陷，同时保留源帧检查。

## 发布结论

把“离线输入/预算/来源校验通过”“某素材复现改善”“新生成样本通过”“跨素材统计改善”分别报告。注明样本数、失败、未知和选择条件，不能只展示成功片。当前 0.3.0 的提示词组装与场景样片是工程能力，尚未通过这套新生成对照；正式 ready 也不是任意图片的一次成功保证。
