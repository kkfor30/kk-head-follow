# 按实际场景选择制作路线

先确定要保留的画面、最终显示大小和动态区域，再选生成背景。深浅背景影响边缘检查；背景纹理、遮挡和旧头是否会露出，决定是否需要分层。不要把绿幕或浅色背景当成所有项目的前提。

| 场景 | 默认起点 | 制作前要确认 |
|---|---|---|
| 独立头像、角色、宠物组件 | 保留完整主体；透明源或避开主体颜色的色键视频 | 头发、耳朵、胡须与完整运动范围不裁断；静态和动态尺寸一致 |
| 可重新制作的新首屏 | 背景、完整角色、接触阴影分别制作，再沿用同一素材生成动作 | 静态构图已成立；多角色分别请求、标定和绘制 |
| 必须保留的简单浅色或深色背景 | 先试 scene/preserve 的少量真实场景合成 | 背景和颈根确实稳定；整块补丁无可见色差。深色不使用 fit-edge-light |
| 原图有纹理、家具、景物，或视频重画了背景 | 移除旧头的 cleanPlate + 逐帧前景 Alpha | 补全头部移动后露出的背景，保留身体承接层；先检查几帧再批处理 |
| 前景有手、道具、头发或另一角色遮挡 | 上一条路线 + 单独的前景遮挡层 | 前景在动态头部之上；若遮挡关系随动作改变，需要逐帧遮罩，静态层不够 |
| 原图含多个角色 | 每条请求只驱动一个目标，独立动作与标定 | 默认近景便于看清眼神；可保留静止邻居或场景作上下文，但不得遮挡目标、挤掉运动余量或承担第二条动作任务 |

**选择背景方法：**

- scene/preserve 保留生成片中的局部背景，适合实际匹配的画面。轻微整体色偏/位移可有限校色或配准；不靠加大羽化修纹理重画。
- fit-edge-light 只用于可靠的简单浅色背景，先核查浅色衣物、毛发和抗锯齿边缘。它不能去黑底或重建复杂背景。
- 需要透明头部时，有真实 Alpha 就复用；没有则选择色键或前景分离。绿、洋红等色键由主体颜色决定，和网页是黑底还是白底无必然关系。黑发角色不应因为网页深色就改用黑色键。
- 生成模型通常交付 RGB 视频。输入 PNG 带 Alpha 不等于输出透明；`alpha-matte` 提示词路线也只是为后续分离准备，不要求模型虚构 Alpha。
- cleanPlate 需要真实补全旧头后面的内容。抠掉新头的背景不会移除底图旧头；羽化还可能让旧轮廓透出。

坐标沿用 [asset-contract.md](asset-contract.md)：原图中的 crop、保持比例后的 renderSize、视频中的 motionCrop 分别记录。头部输入可以比最终绘制区大，但缩放和颈根位置要可追溯。输入仍保留原表情和嘴部状态；固定颈根不等于冻结所有颈部皮肤。

动作与眼神初筛后运行 [scene-samples.md](scene-samples.md)，覆盖极端转头、上下方向、旧轮廓和遮挡边界。通过这一步才值得做全片抠图与图集。已经有同素材有效观察时复用，不重复生产。
