# 冻结范围与示例

版本：0.2.0-experimental.1。状态：实验版。

## Agent 的执行范围

主流程是已有连续视频的实际方向识别、裁段、可选补帧、Alpha/背景处理、图集、鼠标映射及实际页面候选。生成视频是可选入口，按 generation-planning.md 选择同图闭环、动作参考或分段路线；默认预算仅含一次 5 秒试片，路线需要更多时长、参考视频或多个片段时先核对已有授权，不能把预算默认值当动作设计标准。已有可用视频不重新生成。

新建复杂场景优先使用同一套无角色背景、透明完整角色与阴影层；这降低拼接风险，不保证动态融合。保留旧照片时可做进阶局部替换，但不能以羽化承诺消除身体差异、旧头轮廓或背景纹理。

完整方向环仅覆盖外围姿态。当前 assets/head-follow.mjs 在中性区、移出窗口等情况下清除动态层显示底图；它没有自然正脸过渡系统。进入时从目标角度开始，也没有从静态正脸到任意方向的连续过渡素材。不得描述为已经实现自然回正。用户要求自然进入/退出时，先核查实际过渡素材，作为独立需求交付或说明缺项；不得强制所有方向绕经某个固定角度来掩盖缺帧。

逐帧检查仍包含 Agent 视觉判断。像素指标、测试通过、用户喜欢某个演示，不等于自动语义验收或新图成功率。完整方向候选、有限方向预览、鼠标控制动作相位与合成播放按 iteration-delivery.md 分开交付。实验 preview 清单不含 directionFrames，不能获得正式 ready。

0.2 新增请求级输入审查、三条路线、模型能力约束、扩写回执、修复换参考和独立实验预览。这些功能接受离线工程测试；未据此宣称新策略提高了实际视频生成成功率，也未完成新的 ZenMux 付费端到端验证。历史任务可继续查询，不需要按新 schema 重新提交。

## 公开演示与素材

[README](../README.md) 展示维护者提供的网页效果录屏。录屏是效果展示，不是可直接编译的输入视频，也不证明任意新素材都能达到同样效果。

公开包不包含历史项目的角色图、生成原片、提示词记录、方向标定或任务回执。请使用自己的输入素材，并重新完成方向标定与质量检查。

版本升级保留旧生成产物和原预算记录。现有测试只支持工程行为，不代替新素材和交互验收；成功率评估见 [generation-evaluation.md](generation-evaluation.md)。
